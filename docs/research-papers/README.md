# CISpaces research publications

These publications document the original CISpaces research, architecture, collection and fact-extraction pipeline, argumentation, provenance, and report generation.

> **Note:** This directory currently contains a bibliography with links, **not local PDF copies**. Obtain and retain PDFs only when permitted by their respective licences. Do not describe links as bundled PDFs.

## Key technical papers

1. **CISpaces.org: From Fact Extraction to Report Generation** (Cerutti et al., 2018). Primary reconstruction reference for the Stanford dependency parser, OpenIE/ReVerb extraction, argumentation, and NLG pipeline.
   - [PDF — University of Southampton repository](https://eprints.soton.ac.uk/425175/1/aFAIA305_0269_1_.pdf)
   - [Alternative author-hosted PDF](https://www.southampton.ac.uk/~sem03/comma-2018-final.pdf)

2. **Human-Machine Collaboration in Intelligence Analysis: An Expert Evaluation** (Toniolo et al., 2023). Evaluation of collaborative intelligence analysis capabilities and analyst workflows.
   - [PDF — Southampton repository](https://eprints.soton.ac.uk/472703/2/1_s2.0_S2667305322000886_main.pdf)

3. **Conversational Intelligence Analysis** (Toniolo et al., 2016). Integration of conversational collection/analysis approaches.
   - [Cardiff research repository — PDF available on page](https://orca.cardiff.ac.uk/id/eprint/91470/)

4. **A Tool to Highlight Weaknesses and Strengthen Cases: CISpaces.org** (Cerutti et al., 2018). Argumentation and case analysis.
   - [Cardiff research repository — PDF available on page](https://orca.cardiff.ac.uk/id/eprint/117478/)

5. **Argumentation-Based Collaborative Intelligence Analysis in CISpaces** (Toniolo et al., 2014). Foundational reasoning and collaborative analysis.
   - [University of St Andrews publication page](https://research-portal.st-andrews.ac.uk/en/publications/argumentation-based-collaborative-intelligence-analysis-in-cispac/)

6. **Argumentation-Based Sense-Making Exploiting Open Sources** (2018). Related paper on open-source argumentation and sense-making.
   - [Publisher DOI; full text may require access](https://doi.org/10.1117/12.2306217)
